The ``add_integer`` function adds two integers.
>>> add_integer = __import__('0-add_integer').add_integer

Basic usage:
>>> add_integer(1, 2)

Default value for b:
>>> add_integer(1)

Floats are cast to integers:
>>> add_integer(1.9, 2.1)
3
Negative numbers:
>>> add_integer(-3, 5)
2
Both floats:
>>> add_integer(3.7, 4.2)
7
